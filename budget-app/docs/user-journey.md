# User Journey

**Persona:** Client interested in a quick price estimate for digital services, without unnecessary meetings.

| Stage | Action | Feeling | UX opportunity |
|-------|--------|---------|----------------|
| Discover | Lands on the page | Curious | Clear title and visual hierarchy |
| Choose | Selects services | Confident | Real-time total with € symbol |
| Customize | Sets pages and languages | Doubtful | Info modal (ⓘ) explaining costs |
| Request | Fills in the form | Cautious | Clear validation, minimal fields |
| Receive | Sees confirmation and link | Satisfied | Success feedback, copy-link button |
| Share | Sends the URL | Proud | Complete and readable detail page |

**Sales team journey:** opens history → searches by name → sorts by amount/date → opens detail → reviews or resends the budget.
